# Boccantina — estado del preview operativo

**Corte:** 23 de octubre de 2026, 18:05 (UTC−04:00).
**Rama de revisión:** `preview/hero-a`.
**Alcance:** preview local y demostración estática; no es `boccantina.com` en producción.

## Avance disponible

- Central local con inicio de sesión, cuenta propietaria, usuarios del equipo, roles y permisos por operación. Cocina, recepción, caja y meseros disponen de accesos diferenciados. Las cuentas y sesiones reales no se incluyen en Git.
- Gestión de mesas, QR, reservas, comandas y cobros en el preview local. Un mesero con perfil vinculado puede consultar y tomar mesas disponibles; la selección de mesa durante una orden conserva los productos ya añadidos.
- Pedidos por mesa, caja y retiro, con destinos de producto para consumir aquí o llevar. Cocina recibe las comandas sin importes ni datos de pago. El servidor comprueba permisos y cambios de estado.
- Catálogo administrativo con biblioteca reutilizable de extras y control manual de disponibilidad. Los precios históricos de las comandas se conservan.
- Los recursos y páginas estáticas del snapshot se generan desde `preview-src/` con `npm.cmd run apply:heroes`.

## Enlaces y modo de revisión

- Rama de código: <https://github.com/SebaSB115/boccantina-preview/tree/preview/hero-a>.
- Demo pública de GitHub Pages: <https://sebasb115.github.io/boccantina-preview/>. Un workflow publica el snapshot al subir esta rama. La demo usa almacenamiento del navegador y no comparte pedidos entre dispositivos.
- Preview privado local: ejecutar `npm.cmd ci`, `npm.cmd run admin:setup` y `npm.cmd run serve`; después abrir `http://localhost:4174/admin/login/`. El servidor local, las cuentas, los permisos y la API no se ejecutan en GitHub Pages.

## Pendiente antes de producción

El servidor local usa HTTP y sesiones en memoria. Antes de una instalación real se necesita infraestructura con HTTPS, persistencia y copias de seguridad, además de validar en el servidor los importes enviados por clientes. La demo pública no ofrece autenticación privada ni sincronización entre dispositivos.
